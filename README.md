# Phishing Awareness Training

**Recognize. Think. Verify.**

A cybersecurity awareness training project developed as part of my Cybersecurity Internship with CodeAlpha.

**Author:** Agwasie Blessing Uchechi  
**Role:** Cybersecurity Intern — CodeAlpha  
**Project Type:** Cybersecurity Awareness and Education


## 📌 Project Overview

Phishing is a common cyberattack in which attackers impersonate trusted individuals or organizations to trick people into revealing sensitive information, clicking malicious links, opening harmful attachments, or sending money.

This project focuses on educating users about phishing attacks, social engineering techniques, and practical ways to identify and avoid suspicious messages and websites.

The training was developed as a 15-slide educational presentation designed to improve cybersecurity awareness and encourage safer online behaviour.

## 🎯 Project Objectives

The objectives of this project are to:

- Explain phishing and how it works.
- Identify common types of phishing attacks.
- Recognize suspicious emails and fraudulent websites.
- Understand the psychological tactics used in social engineering.
- Promote safe online practices.
- Explain the appropriate response to a suspected phishing incident.
- Reinforce learning through interactive quizzes.

## 📚 Topics Covered

### 1. Introduction to Phishing
An overview of phishing, its purpose, and how attackers deceive victims.

### 2. Types of Phishing Attacks
The training explains:

- Email phishing
- Spear phishing
- Smishing
- Vishing
- Whaling

### 3. How Phishing Works
An explanation of how attackers create deceptive messages, impersonate trusted sources, pressure victims into acting, and attempt to obtain sensitive information or unauthorized access.

### 4. Identifying Suspicious Emails
Common warning signs include:

- Suspicious sender addresses
- Urgent or threatening language
- Unusual links
- Unexpected attachments
- Requests for passwords or one-time passwords (OTPs)
- Unusual wording
- Offers that seem too good to be true

### 5. Identifying Fraudulent Websites
The training explains how to inspect website addresses, identify suspicious domains, and independently navigate to official websites instead of trusting unexpected links.

It also highlights that HTTPS alone does not guarantee that a website is legitimate.

### 6. Social Engineering
An overview of psychological manipulation techniques commonly used by attackers, including:

- Fear
- Urgency
- Authority
- Curiosity
- Rewards and incentives

### 7. Real-World Phishing Example
The presentation discusses the 2017 Google Docs phishing attack to demonstrate how malicious applications and deceptive invitations can exploit trust.

### 8. Phishing Prevention
Recommended protective measures include:

- Using strong, unique passwords
- Enabling Multi-Factor Authentication (MFA)
- Keeping devices and applications updated
- Avoiding unexpected links and attachments
- Never sharing passwords or OTPs
- Independently verifying unusual requests
- Reporting suspicious messages

### 9. Responding to a Suspected Phishing Attack
The training outlines appropriate actions to take after clicking a suspicious link, including stopping further interaction, changing compromised passwords, enabling MFA, and reporting the incident.

It also addresses what to do if a suspicious file has been downloaded.

### 10. Interactive Knowledge Assessment
Two scenario-based quizzes reinforce the lessons:

- Identifying warning signs in a suspicious bank message.
- Verifying an unusual gift-card request supposedly sent by a manager.
